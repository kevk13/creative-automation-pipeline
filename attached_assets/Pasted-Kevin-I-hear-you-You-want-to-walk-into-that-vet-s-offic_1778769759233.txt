PHASE 6 — Step 2: gatherAssets (Mastra agent)
Build the agent in /src/agents/assetGatherer.ts. The agent uses claude-sonnet-4-5. System prompt: “You are a creative asset coordinator. For each product, first check if a local asset exists. If yes, use it. If no, generate a detailed image generation prompt that captures the product, brand aesthetic, and target audience. Then call the image generator tool to produce the asset.”
Build two tools in /src/tools/:
checkLocalAsset takes a localAssetPath and returns whether the file exists and the absolute path if so.
generateAssetWithGenAI takes a product object, brand context, and target audience. It calls Claude to craft a detailed DALL-E 3 prompt that captures the product description, brand aesthetic (premium, minimalist, ethical), and target audience. Then it calls OpenAI’s DALL-E 3 API to generate an actual 1024x1024 image. Downloads the image from the returned URL using fetch. Saves to /output/generated/{productSlug}.png. Returns the path. Logs token costs for the Claude prompt-crafting call AND the DALL-E generation cost.
The gatherAssets step iterates through each product, calls the agent, and collects asset paths. Returns the brief plus an assets map: productName to assetPath. All wrapped in try/catch.

PHASE 7 — Step 3: renderAspectRatios
Implement renderAspectRatios. For each product asset, use Sharp to produce three versions: 1:1 at 1080x1080, 9:16 at 1080x1920, 16:9 at 1920x1080. Use Sharp’s resize with cover fit strategy and centered position so the product stays focal. Save renders to /output/{productSlug}/{ratio}/base.png. Return the brief plus a renders map: productName to ratio to filepath. Try/catch around each Sharp operation.

PHASE 8 — Step 4: applyOverlay
Implement applyOverlay. For each rendered image, use Sharp’s composite method with an SVG text overlay to place the campaign message. Text rules: bottom third of image, white text with a dark semi-transparent background bar behind it for readability, font size scaled to image width (roughly 6% of width). Save overlaid versions to /output/{productSlug}/{ratio}/final.png. Return renders map updated with final paths.

PHASE 9 — Step 5: organizeOutputs
Implement organizeOutputs. Verify the folder structure is complete: /output/{productSlug}/{ratio}/final.png for every product and ratio combination. Return the manifest.

PHASE 10 — Step 6: checkCompliance (Mastra agent)

Build two tools:

checkLogoPresence sends the image to Claude vision with a prompt asking whether a logo is visible and what it appears to be. Return boolean plus reasoning string.
The compliance step also scans the campaignMessage for any prohibitedWords (case-insensitive substring match). Returns a compliance report with three sections: colorCompliance (per image, score and pass/fail), logoCompliance (per image, advisory only), legalCompliance (whether prohibited words were found, list of any matches).
