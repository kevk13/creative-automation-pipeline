Interview Drill

Volunteer the GAPs before they find them. Lead with strengths, own the holes.

Own these 3 first

  1. Mid-run crash. In-memory state + fire-and-forget. Crash loses the run, frontend 404s. Volunteer it.
  2. How compliance scores. They go line by line. Name the bugs yourself.
  3. Shared output dir. Two runs clobber each other; /manifest returns the wrong run.

Say this, not that

NOT "two AI agents" two bounded orchestration modules. For-loops wrapping tool calls, no reasoning loop.
NOT "every AI call logs cost" per-call tokens + cost for Claude. Gemini image cost is stubbed at $0 today.
NOT "retries on the AI calls" retries on Gemini + Dropbox. Claude prompt + vision not retried yet, known gap.
NOT "Mastra, one-import swap" API-shape compatible so step contracts port. Real Mastra adds resume/persistence I don't have.
NOT "compliance-checked output" two deterministic gates (color, words) + one advisory vision check. Here are the failure modes.

The 10 questions

1. Process restarts mid-run. What happens?
  • Total loss. State only in an in-memory Map.
  • Workflow runs fire-and-forget in the Express process. No queue, no checkpoint.
  • Restart = empty Map. Frontend polls /status, gets 404.
  • Files on disk survive but nothing points to them.
Gap: severe
2. Step 4 fails on asset 30 of 100. What about 1–29?
  • Whole run fails. Every step re-throws on first error.
  • No partial manifest. Assets 1–29 orphaned on disk.
  • Only ComplianceChecker isolates per-item.
Gap: severe
3. Walk me through retry/backoff.
  • base x 2^(n-1), +/-20% jitter, 4 attempts.
  • 429/5xx retry, 4xx terminal, unknown defaults to retry.
  • Applied to Gemini + Dropbox only.
  • Bug to admit: terminal message hardcoded "image generation failed" even for Dropbox.
Gap: minor
4. Non-determinism in a compliance system?
  • Color check + word scan: deterministic. Trust as gates.
  • Gemini (no seed) + vision (no temp 0): non-deterministic.
  • logoPresent can flip between runs. Treat vision as advisory.
Gap: medium
5. Can you reproduce a rejected image?
  • No. You save the PNG + manifest, but not prompt, seed, or model version.
  • Fix: capture prompt + seed + model in the manifest. Small add.
Gap: medium
6. Exactly how does compliance score? (they drill this)
  • Palette: top-5 dominant colors, RGB distance, pass ≥ 0.3. Loose. Scores its OWN overlay bar. Empty palette = 0 = every image FAILS.
  • Logo: Claude vision "any logo/text?" No reference match. Campaign TEXT reads as a logo. No retry, errors swallowed to false.
  • Words: substring scan of campaignMessage ONLY. Not the image, not OCR. False positives possible.
Gap: the big one
7. Two campaigns POST at once. What breaks?
  • Map is keyed by runId, safe. Filesystem is not.
  • One shared output dir = same files overwritten.
  • /manifest + /compliance read the single file, always return the LAST run.
Gap: severe
8. Where's the parallelism in a 100-product run?
  • None. All loops sequential, no Promise.all, no workers.
  • Defensible for a POC: correctness first.
  • Next: bounded per-product concurrency + a queue.
Gap: scale only
9. uploadStatus:failed but run completes. Success or failure?
  • Soft failure by design. Catches per-file, falls back to local path, run still "done".
  • Reasonable, but frame it as deliberate.
  • Gap: top-level status doesn't surface the partial failure.
Gap: minor
10. POC to production. What first?
  • 1. Durable run state + job queue (runs table in the Postgres stub).
  • 2. Per-run output namespacing.
  • 3. Per-item isolation + partial-success manifest.
  • 4. Auth + multi-tenancy (zero auth today; loadFromUrl = SSRF).
  • 5. Harden compliance: temp 0, reference-logo match, OCR for words.
Strongest question. Lead with queue + runs table.
